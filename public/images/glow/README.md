# Фотографии Glow Saratov

Положите сюда фотографии, которые компания передаст для макета. На данный момент реальные фотографии в проект не добавлены; SVG рядом с этим файлом — нейтральные локальные заглушки с пометкой «Фото будет добавлено».

## Нужные файлы

- `hero.webp` — главный интерьерный кадр, горизонтальный или вертикальный с запасом по краям.
- `space-01.webp` — общий вид коворкинга.
- `space-02.webp` — рабочая зона или дополнительный общий план.
- `hair-workplace.webp` — парикмахерское рабочее место.
- `nail-workplace.webp` — место для маникюра/педикюра.
- `cabinet.webp` — отдельный кабинет.
- `details-01.webp` — деталь интерьера.
- `details-02.webp` — вторая деталь интерьера.

Фотографии должны быть предоставлены компанией или сохранены вручную из её аккаунтов с разрешения представителя. Не заменяйте их сторонними фотографиями. После добавления конвертируйте/переименуйте файлы в `.svg`-заглушках, обновив пути в `src/data/glow.ts` и `src/components/Site.tsx`.
